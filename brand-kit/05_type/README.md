# 05_type — the typefaces

## `source-fonts/`
The five typefaces the brand actually uses, as their original variable-font `.ttf` files,
each with its `OFL.txt` licence beside it. **Keep the licence file with the font** — that is
the one condition the SIL Open Font Licence 1.1 asks of you.

| Family | Job | Axes |
|---|---|---|
| Sora | Display, wordmark, headings (Latin) | weight 100–800 |
| Noto Sans | Body text (Latin) | width + weight |
| Noto Sans Bengali | All Bangla | width + weight |
| JetBrains Mono | Code, labels, metadata | weight, plus an italic file |
| Anek Bangla | Optional large Bangla display | width + weight |

For the web you want the **subset woff2 files** in `08_guidebook/assets/fonts/` instead —
same faces, about a tenth of the size, with their licences shipped alongside.

## What is not here
The 29 candidate families that were compared during the type selection are not shipped;
they were working material, not deliverables. The five that won are above. The reasoning,
and the visual comparison that decided it, are in the guidebook's Typography chapter.
