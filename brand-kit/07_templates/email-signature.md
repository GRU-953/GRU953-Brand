# Email signature — GRU953

Three versions of the same signature: **plain text**, a **rich-text description** (for the
signature box in Gmail, Outlook or Apple Mail, where you format by hand), and **HTML** (for
when you can paste code). All three say the same things in the same order, so a reply chain
stays consistent whichever client you are in.

Replace everything in `[square brackets]`, brackets included.

**Two things worth knowing before you choose one:**

- **Most email clients block images until the reader allows them,** and many strip anything
  clever. So every version below reads correctly with no images and no styling at all. The
  logo is a bonus, never the message.
- **Web fonts do not work in email.** Sora will not load in Gmail or Outlook, so the HTML
  version asks for Sora and then falls back to Arial and Helvetica. That is the correct
  behaviour, not a compromise to fix.

## The content, decided once

| Line | What it says | Why it is there |
|---|---|---|
| 1 | [Aninda Sundar Howlader] | Your name, in Meridian, slightly larger. |
| 2 | GRU953 — a one-person software studio | The studio, immediately followed by what it is. This second half is not optional: to a developer, "GRU" also means Gated Recurrent Unit, so the words after the name settle the reading before it drifts. |
| 3 | simple software, built one thing at a time | The descriptor. Approved copy. |
| 4 | [email] · [phone] | Contact. Phone only if you want to be phoned. |
| 5 | [github.com/GRU-953] · [website] | Where the work is. |
| 6 | Simple technology. For everyone. / সহজ প্রযুক্তি। সবার জন্য। | The tagline. See the bilingual rule below. |

**Never in a GRU953 signature:** a quotation, a "sent from my phone" line under your own
signature, a legal disclaimer you did not write, a "please consider the environment before
printing" line, a social icon strip, or your job title inflated past what it is.

## The bilingual rule

Do not put four Bangla lines under four English lines. A doubled signature is twice the
height and reads as a template rather than as a person.

**Instead, three cases:**

1. **Writing in English, to anyone** — English signature, and the Bangla half of the
   tagline on the same last line, after a slash. One line, both languages, and it signals
   the bilingual work without doubling anything.
2. **Writing in Bangla** — the Bangla signature (given in full below). Your name in Bangla
   script, `GRU953` still in Latin capitals.
3. **A formal Bangla document or a Bangladeshi institution** — the Bangla signature, with
   your name repeated in Latin script in brackets on the same line, because forms and
   databases usually need the Latin spelling.

> ⚠ **Unverified:** the Bangla spelling of your name. "Aninda" maps to **অনিন্দ**;
> "Anindya" would be **অনিন্দ্য**. I have written **অনিন্দ সুন্দর হাওলাদার** below.
> Confirm it before you use it anywhere.

## Version 1 — plain text

For a plain-text mail client, a terminal mail tool, a mailing list, or any place styling is
not allowed. The two spaces before each line break are not needed here; the separator is
the middle dot ( · ) with a space either side.

### 1a. English, standard

```text
--
[Aninda Sundar Howlader]
GRU953 — a one-person software studio
simple software, built one thing at a time
[your.email@example.com] · [+880 0000 000000]
github.com/GRU-953 · [example.com]
Simple technology. For everyone. / সহজ প্রযুক্তি। সবার জন্য।
```

### 1b. English, short — for replies inside a thread

```text
--
[Aninda] · GRU953
[your.email@example.com] · github.com/GRU-953
```

### 1c. Bangla

```text
--
[অনিন্দ সুন্দর হাওলাদার]
GRU953 — একজনের সফটওয়্যার স্টুডিও
সহজ সফটওয়্যার, একটা একটা করে বানানো
[your.email@example.com] · [+880 0000 000000]
github.com/GRU-953 · [example.com]
সহজ প্রযুক্তি। সবার জন্য।
```

### 1d. Bangla, formal — with the Latin spelling for forms and records

```text
--
[অনিন্দ সুন্দর হাওলাদার] ([Aninda Sundar Howlader])
GRU953 — একজনের সফটওয়্যার স্টুডিও
[শহর], বাংলাদেশ
[your.email@example.com] · [+880 0000 000000]
সহজ প্রযুক্তি। সবার জন্য।
```

**On the `--` at the top:** two hyphens then a line break is the long-standing convention
for "the signature starts here", and many mail clients use it to hide the signature when
quoting a reply. Keep it in plain text. Leave it out of the rich-text and HTML versions,
where the client marks the signature itself.

## Version 2 — rich text, described step by step

Use this when you are typing into a signature box and formatting by hand — Gmail Settings,
Outlook, Apple Mail. There is no code to paste; you are just following instructions.

**Before you start:** know that Sora will not be available in an email signature box. Use
Arial. This is expected, and the signature is still on brand, because in email the brand
lives in the colour, the wording and the order — not the typeface.

1. Open your mail client's signature settings.
   - Gmail: click the gear icon, then **See all settings**, then scroll to **Signature**.
   - Outlook (web): click the gear icon, then **Mail**, then **Compose and reply**.
   - Apple Mail: menu **Mail**, then **Settings**, then **Signatures**.
2. Click **Create new** and name the signature `GRU953 English`.
3. Type your name on the first line: `[Aninda Sundar Howlader]`.
4. Select that name. Set the font to **Arial** and the size to **medium** (or 15px if the
   box asks for a number). Set it **bold**.
5. With the name still selected, set the text colour using the custom-colour box and the
   hex code **`1A1753`** (Meridian). Do not pick the nearest blue from the swatch grid; type
   the hex code.
6. Press Enter. Type: `GRU953 — a one-person software studio`
7. Press Enter. Type: `simple software, built one thing at a time`
8. Select both of those two lines. Set the font to **Arial**, size **small** (13px), and the
   colour to hex **`0B0E14`** (Ink). Not bold.
9. Press Enter. Type your contact line: `[your.email@example.com] · [+880 0000 000000]`
   - Type the dot separator as a space, then `·`, then a space. On Windows you can copy it
     from here; on a Mac it is Option and the full-stop key.
10. Press Enter. Type: `github.com/GRU-953 · [example.com]`
11. Select both contact lines and set them to Arial, **small** (13px), Ink `0B0E14`. If your
    client turns the addresses into links automatically, leave them; if it colours them a
    bright blue, select each link and set its colour to `1A1753`.
12. Press Enter. Type the tagline:
    `Simple technology. For everyone. / সহজ প্রযুক্তি। সবার জন্য।`
13. Select the tagline. Set it to Arial, **small** (13px), **italic off**, and colour
    `1A1753`.
    - **Do not make the Bangla italic.** Bangla has no italic tradition, and a slanted
      Bangla word looks like a rendering fault. If your client italicises the whole line by
      default, turn italics off for the entire line rather than for half of it.
14. Optional logo. Click the insert-image button, choose **Web address (URL)**, and paste
    the hosted address of `logo-horizontal-light.svg`.
    - Set its width to **180px**.
    - Set the alt text to exactly `GRU953`.
    - If the box will not accept SVG, use a PNG exported at 360px wide and displayed at
      180px, so it stays sharp on a high-resolution screen.
    - The logo goes **above** your name, with one blank line after it.
15. Set **"Insert signature on replies"** to the short version from 1b, if your client
    allows two signatures. If it allows only one, use the standard version and accept the
    repetition.
16. Click **Save**.
17. Send yourself one test email. Open it on your phone. Check three things: the name is
    dark navy and not black, the Bangla renders as Bangla and not as boxes, and the whole
    signature is under seven lines.

**If the Bangla shows as empty boxes** on the phone you tested with, that device has no
Bengali font available. Do not fix it by turning the Bangla into an image — an image cannot
be searched, copied or read aloud by a screen reader. Use plain-text version 1a instead for
that correspondence, and leave the tagline in English only.

## Version 3 — HTML

Paste this where a mail client or CRM accepts raw HTML. It uses a table, inline styles and
no web fonts, because that is what email clients reliably support.

**Colour rules already applied, so do not change them:** the name and the tagline are
Meridian `#1A1753` on white, which measures 16.26:1 — comfortably past WCAG 2.2 AAA.
Daybreak `#FFAB8E` is **not** used for any text or any thin line here: on white it measures
about 1.83:1, so it would be unreadable. Daybreak belongs on Meridian or Ink, never on
paper.

```html
<!-- GRU953 email signature, HTML version.
     Replace every [bracketed] value. Keep the inline styles: email clients strip
     stylesheets. Keep the alt text: many readers see it instead of the image. -->
<table cellpadding="0" cellspacing="0" border="0" style="border-collapse:collapse;">
  <tr>
    <td style="padding:0 0 10px 0;">
      <!-- Optional logo. Must be an absolute https:// address that stays online.
           Delete this whole <td> block if you would rather have no image. -->
      <img src="https://[your-domain]/assets/logo-horizontal-light.png"
           alt="GRU953" width="180" height="[height]"
           style="display:block;border:0;outline:none;text-decoration:none;">
    </td>
  </tr>
  <tr>
    <td style="font-family:Sora,Arial,Helvetica,sans-serif;font-size:15px;
               line-height:1.4;font-weight:700;color:#1A1753;padding:0 0 2px 0;">
      [Aninda Sundar Howlader]
    </td>
  </tr>
  <tr>
    <td style="font-family:Arial,Helvetica,sans-serif;font-size:13px;
               line-height:1.5;color:#0B0E14;padding:0 0 8px 0;">
      GRU953 — a one-person software studio<br>
      simple software, built one thing at a time
    </td>
  </tr>
  <tr>
    <td style="border-top:1px solid #1A1753;padding:8px 0 0 0;
               font-family:Arial,Helvetica,sans-serif;font-size:13px;
               line-height:1.6;color:#0B0E14;">
      <a href="mailto:[your.email@example.com]"
         style="color:#1A1753;text-decoration:none;">[your.email@example.com]</a>
      &nbsp;·&nbsp; [+880 0000 000000]<br>
      <a href="https://github.com/GRU-953"
         style="color:#1A1753;text-decoration:none;">github.com/GRU-953</a>
      &nbsp;·&nbsp;
      <a href="https://[example.com]"
         style="color:#1A1753;text-decoration:none;">[example.com]</a>
    </td>
  </tr>
  <tr>
    <td style="padding:8px 0 0 0;font-family:Arial,Helvetica,sans-serif;
               font-size:13px;line-height:1.7;color:#1A1753;letter-spacing:0;">
      Simple technology. For everyone. &nbsp;/&nbsp;
      <span lang="bn" style="font-family:'Noto Sans Bengali',Arial,sans-serif;
                             font-size:14px;line-height:1.7;letter-spacing:0;">সহজ
        প্রযুক্তি। সবার জন্য।</span>
    </td>
  </tr>
</table>
```

### The Bangla-specific parts of that markup, and why they are there

- **`lang="bn"`** tells a screen reader to switch to Bangla pronunciation. Without it the
  line is read out in an English voice and is unintelligible.
- **`font-size:14px` on the Bangla** against 13px for the English. Bangla stacks marks above
  and below the line, so it needs a point more size to stay legible. *This is a working
  allowance from practice, not a measured standard — unverified as a formal figure.*
- **`line-height:1.7`** on the tagline row, for the same reason.
- **`letter-spacing:0`, stated explicitly.** Some clients and CRMs inject letter-spacing
  into signatures. On Bangla it pulls the মাত্রা (the horizontal stroke over most letters)
  apart into dashes and detaches vowel marks. Setting it to zero by hand stops that.
- **No `text-transform:uppercase` anywhere.** Bangla has no capital letters, so it would do
  nothing to the Bangla and shout only at the stray Latin words.
- **`'Noto Sans Bengali'` first, then Arial.** Almost no email client has Noto Sans Bengali
  installed, so in practice the reader's own system Bengali font renders it. That is fine.
  Asking for the right font first costs nothing and helps the few readers who have it.

### Bangla HTML version

For the whole signature in Bangla, use the same table and swap these three cells:

```html
<!-- name -->
[অনিন্দ সুন্দর হাওলাদার]
<!-- studio and descriptor -->
GRU953 — একজনের সফটওয়্যার স্টুডিও<br>
সহজ সফটওয়্যার, একটা একটা করে বানানো
<!-- tagline -->
সহজ প্রযুক্তি। সবার জন্য।
```

Add `lang="bn"` to the `<table>` tag itself when the signature is entirely in Bangla, and
raise every `font-size` by 1px. `GRU953` stays in Latin capitals inside the Bangla lines —
it is a name, not a word to be translated.

## Check it once, then forget it

1. Does the signature still make sense with images blocked?
2. Is it seven lines or fewer?
3. Is `GRU953` one word, uppercase, followed the first time by what it is?
4. Is any text set in Daybreak on white? It must not be.
5. On a phone, does the Bangla render as Bangla rather than as boxes?
6. Is there a quotation, a disclaimer or a printing plea? Delete it.
